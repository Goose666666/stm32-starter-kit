STM32 入门环境安装包
配合江协科技《STM32入门教程-2023版》
====================================

先做这件事：双击打开「安装说明.html」，用浏览器看，里面有完整的 6 步说明和出错排查。

下面是最短版，供快速参考。

芯片：STM32F103C8T6
库：  标准库 StdPeriph，不是 HAL 库

----------------------------------------
这个包里有什么
----------------------------------------

01-器件包/     Keil 的芯片支持包，双击即可离线安装，不用联网
               教程只需要 Keil.STM32F1xx_DFP.2.4.1.pack

               新建工程时要用，官方资料包里也有一份，两者一样

安装说明.html   完整步骤和出错排查

----------------------------------------
六步概览
----------------------------------------

1. 下载江协科技官方资料包，见上面的网盘链接

2. 官网下载并安装 Keil MDK
   安装路径必须填 C:\Keil_v5
   路径里不能有中文和空格，不要装在下载文件夹或桌面

3. 安装器件包
   打开 01-器件包 文件夹，依次双击
     ARM.CMSIS.5.9.0.pack
     ARM.CMSIS.6.3.0.pack
     Keil.STM32F1xx_DFP.2.4.1.pack
   装完完全退出 Keil 再重开

   注意：不要用软件里的 Pack Installer 在线安装。
   国内经常连不上，下坏的文件会让整个芯片列表都读不出来。

4. 安装 ST-Link 驱动
   打开 C:\Keil_v5\ARM\STLink\USBDriver
   64 位系统运行 dpinst_amd64.exe
   插上 ST-Link V2，设备管理器里看到 STMicroelectronics STLink 就成了
   ST-Link 和板子之间接四根线：SWDIO SWCLK GND 3.3V

5. 新建工程，跟教程 P4 做
   工程要放纯英文路径，比如 D:\stm32\Project01
   芯片选 STM32F103C8
   必须定义宏 USE_STDPERIPH_DRIVER
     位置：魔术棒图标 -> C/C++ 标签 -> Define 输入框

6. 配置下载器
   魔术棒 -> Debug 标签 -> 下拉选 ST-Link Debugger
   魔术棒 -> Flash Download 标签 -> 勾上 Reset and Run

----------------------------------------
三个最常见的坑
----------------------------------------

Vendor / Device / Toolset 显示 unknown
  这不是错误。还没在下面的树里选中芯片而已。
  点中一个具体型号，三行会自动填好。

Pack Installer 顶上出现红色 ERRORS，Cannot load PDSC Files
  在线目录缓存下坏了。
  关掉 Keil，把 C:\Keil_v5\ARM\PACK\.Web 里的文件全删，
  然后改用第 3 步的离线方式装包。

编译报几十上百个错，找不到头文件
  多半是宏 USE_STDPERIPH_DRIVER 没定义，
  或者 Include Paths 里漏加了放头文件的文件夹。
