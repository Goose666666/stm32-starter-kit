配合江协科技 STM32 入门教程 2023 版

STM32 入门环境安装

把 Keil 装好，能新建工程、选中芯片、编译通过、把程序烧进板子。做完就能跟着教程 P5 开始写代码。全程约 50 分钟，一半时间在等下载和安装。

芯片 STM32F103C8T6 标准库，非 HAL MDK 5.36 6 步

先看这条，不然装完编译不过

一定要装 MDK 5.36，不要装官网首页的最新版。

Keil 从 5.37 开始不再自带 Arm Compiler 5，只剩 Arm Compiler 6。而教程用的标准库工程默认就是 AC5 编的。装了新版，前面每一步都顺利，直到 P4 建完工程一按编译，才会冒出一堆看不懂的错，而且报错信息完全指不到根因。

这一条是实测的，不是推测。同一个标准库工程、同一份代码，只切换编译器：

编译器错误警告能否生成 hex
Arm Compiler 500可以
Arm Compiler 6446109不行

AC6 报的错集中在 core_cm3.h，满屏 unknown type name 'inline'。标准库是 2011 年的代码，AC6 不吃这套写法。而 5.41 里 armcc.exe 根本不存在，想切都切不了。

这个包里已经备好的

  • 标准库 02-标准库，V3.5.0 官方完整版
  • 工程模板 03-工程模板，建好的空工程，打开就能编译
  • 本说明，含出错排查

需要自己下载的

  • Keil MDK 5.36 本体，商业软件别人不能代传
  • 江协科技官方资料包，里面有全部例程、原理图和模块资料

安装步骤

1

下载江协科技官方资料包对应 P3

跟着教程学的必备资料，全部例程源码、原理图、模块手册都在里面。

  1. 网盘 pan.baidu.com/s/1h_UjuQKDX9IpP-U1Effbsw
  2. 提取码 dspb
  3. 下载后解压，解压密码是 32
下不动怎么办

官网 jiangxiekeji.com/download.html 有最新链接。实在下不了，本包里的标准库和工程模板够你走到 P5，但例程和原理图还是得从官方资料包拿。

2

下载并安装 Keil MDK 5.36

注意版本，理由见页面开头那条。

  1. 下载地址 armkeil.blob.core.windows.net/eval/MDK536.EXE，这是 Arm 官方存储，直接下，不用注册
  2. 文件约 891 MB
  3. 运行安装程序，一路下一步
  4. 安装路径填 C:\Keil_v5，C 盘空间不足就填 D:\Keil_v5，实测装 D 盘完全正常
  5. 中途弹出驱动安装确认框，点安装
路径要求

路径里不能有中文、空格，不要装在下载文件夹或桌面。装错位置后面会冒出各种莫名其妙的错误，而且很难查。

整个安装约占 2.8 GB，先看看盘够不够。

装在 D 盘的话，还要多做一步

就算你把 Keil 装到了 D 盘，器件包默认仍然往 C:\Users\你的用户名\AppData\Local\Arm\Packs 里塞，光是自带的包就有 1 GB。C 盘紧张的话这一步必须改。

改法：用记事本打开 D:\Keil_v5\TOOLS.INI，把第一段里的 RTEPATH="C:\Users\...\Arm\Packs" 改成 RTEPATH="D:\Keil_v5\ARM\PACK"，保存。已经装好的包整个文件夹剪切过去即可。

3

安装器件包对应 P3

器件包告诉 Keil 有哪些芯片、内存多大、怎么烧写。没有它，新建工程时芯片列表是空的。

  1. 打开本文件夹下的 01-器件包
  2. 双击 Keil.STM32F1xx_DFP.2.3.0.pack，等进度窗口自己跑完
  3. ARM.CMSIS.5.9.0.pack 一般用不上，MDK 自带。装完工程编译报缺 CMSIS 时再双击它
  4. 装完把 Keil 完全退出再重新打开
不要用 Pack Installer 在线装

软件里那个 Pack Installer 要连 Keil 的服务器，国内经常连不上或下到一半断掉，下坏的文件会让整个器件列表都读不出来。本包的离线文件就是为了绕开这件事。

做完的标志新建工程时能看到 STMicroelectronics 这一项
4

安装 ST-Link 驱动

教程用的是外置 ST-Link V2 下载器，就是那个 U 盘模样的小东西。驱动不用另外下载，Keil 自带。

  1. 打开 C:\Keil_v5\ARM\STLink\USBDriver，装在 D 盘就是 D:\Keil_v5\ARM\STLink\USBDriver
  2. 64 位系统运行 dpinst_amd64.exe，32 位运行 dpinst_x86.exe
  3. 把 ST-Link V2 插到电脑 USB 口
  4. 右键开始菜单打开设备管理器，看到 STMicroelectronics STLink 就成了
接线

ST-Link 和最小系统板之间接四根杜邦线，一一对应：SWDIO、SWCLK、GND、3.3V。教程里有接线图，照着接，别接反。

5

新建工程对应 P4

跟着教程视频做。下面只说环境相关的关键点和最容易卡住的地方。

  1. 菜单 Project → New µVision Project
  2. 存到纯英文路径，比如 D:\stm32\Project01，文件夹名和工程名都别用中文
  3. 弹出 Select Device 窗口，展开 STMicroelectronics → STM32F1 Series，一层层点到 STM32F103C8，点中它
  4. 下一个窗口 Manage Run-Time Environment 直接点 Cancel，教程用标准库，不用这里的组件
  5. 按教程把标准库文件复制进工程，库在本包 02-标准库 里
  6. 按教程添加分组、添加头文件路径
  7. 定义宏 USE_STDPERIPH_DRIVER，位置在魔术棒图标 → C/C++ 标签 → Define 输入框
别被 unknown 吓到

Select Device 窗口刚打开时，上面 Vendor、Device、Toolset 三行都显示 unknown。这是正常的，因为还没选芯片。在下面树里点中一个具体型号，三行会立刻自动填好。

建不出来可以用现成的

本包 03-工程模板 里有一个建好的工程，标准库、宏、头文件路径全配好了，复制到纯英文路径打开就能编译。建议还是自己照 P4 建一遍，模板留作对照和兜底。

做完的标志编译通过，0 Error 0 Warning
6

配置下载器并烧录

  1. 点工具栏的魔术棒图标，打开工程设置
  2. 进 Debug 标签，右上角下拉框选 ST-Link Debugger
  3. 点旁边的 Settings，右边能读出一串 SW Device 编号就说明板子连上了
  4. 进 Flash Download 标签，勾上 Reset and Run，烧完自动运行，不用手动按复位
  5. 回主界面点下载按钮，看到 Verify OK 就成功了
全部完成可以开始 P5 GPIO 输出了

出错了怎么办

编译报一大堆错，说找不到头文件或者符号未定义

新建工程最常见的三个疏漏，按顺序查：

  1. 装了 5.37 以上的 Keil。没有 AC5，标准库工程编不过。卸掉换 5.36
  2. 宏没定义。魔术棒 → C/C++ 标签 → Define 框里必须填 USE_STDPERIPH_DRIVER。少了它标准库头文件全部不生效，会报几十上百个错
  3. 头文件路径没加。同一个标签里 Include Paths 要把工程中每个放了 .h 的文件夹都加进去，一个都不能漏

芯片列表是空的，只有一项 ARM

器件包没装上，或者被删掉了。

  1. 回第 3 步，双击 .pack 文件离线安装
  2. 装完必须完全退出 Keil 再重开，否则列表不刷新

Pack Installer 顶上出现红色 ERRORS，写着 Cannot load PDSC Files

在线目录缓存下坏了。那些是从网上下的芯片索引文件，下载中断或被网络拦截，存下来就是坏的。

  1. 完全关掉 Keil 和 Pack Installer
  2. 打开 C:\Keil_v5\ARM\PACK\.Web，把里面文件全删。这个文件夹只是缓存，删了不影响已装的东西
  3. 重开 Keil，改用第 3 步的离线方式装包

ERRORS 下面的 Del 按钮删的是坏缓存，点了安全。但 Packs 标签页里已装好的器件包千万别删。

点下载报错，找不到 ST-Link 或 No target connected

  1. 确认驱动装了，见第 4 步
  2. 确认四根杜邦线接对：SWDIO、SWCLK、GND、3.3V，接反了读不到芯片
  3. 确认用的是数据线，有些 USB 线只能充电不能传数据
  4. 魔术棒 → Debug 标签，下拉框要选 ST-Link Debugger，不是默认的 ULINK

编译报错说超过 32K 限制

MDK-Lite 免费版的容量上限，学到后面才会撞上。遇到了去 Arm 官网申请 MDK Community Edition，非商业用途免费，没有这个限制。申请完在 Keil 里点 File → License Management 填授权码。

关于这个教程

江协科技的 STM32 入门教程 2023 版一共 50 集。P1 到 P2 是介绍，P3 讲软件安装，P4 讲新建工程，从 P5 开始才真正写代码。前四集是纯配置，卡住很正常，过了就顺了。

它用的是标准库不是 HAL 库。这两套是不同的写法，网上搜到的代码如果是 HAL 的，直接抄进来编译不过。搜资料时注意区分。

这套环境验证到什么程度

整套流程在一台 Windows 11 上从零走了一遍：装 MDK 5.36 到 D 盘、离线装器件包、把包目录迁到 D 盘、用本包的工程模板编译。

结果是 0 错误 0 警告，生成 hex 3283 字节，程序体积 Code=896 RO-data=252 ZI-data=1024，标准库 23 个外设驱动全部编过。

没验证的只有一项：烧录到真板子。手上没有 F103 板子和 ST-Link，第 4 步和第 6 步是照官方文档写的，你插上板子实际试一次就知道。

本页所有版本号、路径、报错信息都来自实际操作，不是照搬网上教程。卡在哪一步，把那一步的截图发回来。
