STM32 入门环境安装

把 Keil 装好，能新建工程、选中芯片、把程序烧进板子。做完这些就能跟着教程 P5 开始写代码。全程大约 50 分钟，一半时间在等下载和安装。

芯片 STM32F103C8T6 标准库，非 HAL 6 步

这个包里已经备好的

  • Keil 器件包，在 01-器件包 里，双击离线安装，不用联网
  • 标准库 STM32F10x_StdPeriph_Lib_V3.5.0，在 02-标准库 里，新建工程要用它
  • 本说明，含出错排查

需要自己下载的

  • Keil MDK 本体，Arm 官网注册后下载，别人不能代传
  • 江协科技官方资料包，里面有全部例程、原理图和模块资料

安装步骤

1

下载江协科技官方资料包对应 P3

这是跟着教程学的必备资料，全部例程源码、原理图、模块手册都在里面。

  1. 网盘地址 pan.baidu.com/s/1h_UjuQKDX9IpP-U1Effbsw
  2. 提取码 dspb
  3. 下载后解压，解压密码是 32
找不到或者下不动怎么办

官网 jiangxiekeji.com/download.html 有最新链接，链接失效可以发邮件问。

如果网盘实在下不下来，本包 02-标准库 里的标准库能让你先把工程建起来，跟着教程走到 P5 没问题。但例程和原理图还是得从官方资料包拿。

2

安装 Keil MDK

去 Arm 的 Keil 官网下载 MDK 安装包，注册一个免费账号即可下载。

  1. 运行安装程序，一路下一步
  2. 安装路径填 C:\Keil_v5
  3. 中途弹出驱动安装确认框，点安装
最重要的一条

路径里不能有中文、空格，也不要装在下载文件夹或者桌面。装错位置后面会冒出各种莫名其妙的错误，而且很难查。就用 C:\Keil_v5，别改。

3

安装器件包对应 P3

器件包告诉 Keil 有哪些芯片、内存多大、怎么烧写。没有它，新建工程时芯片列表是空的。

  1. 打开本文件夹下的 01-器件包
  2. 双击 ARM.CMSIS.5.9.0.pack，等它装完
  3. 双击 ARM.CMSIS.6.3.0.pack，两个版本可以共存，都装上更保险
  4. 双击 Keil.STM32F1xx_DFP.2.4.1.pack，这个是教程用的 F103 系列，必装
  5. 另外两个 F4 和 H5 的包用不到，先不用管
  6. 全部装完，把 Keil 完全退出再重新打开
不要用 Pack Installer 在线装

软件里那个 Pack Installer 要连 Keil 的服务器，国内经常连不上或者下到一半断掉，下坏的文件会让整个器件列表都读不出来。这个包里的文件就是为了绕开这件事。

做完的标志新建工程时能看到 STMicroelectronics 这一项
4

安装 ST-Link 驱动

教程用的是外置的 ST-Link V2 下载器，就是那个 U 盘模样的小东西。驱动不用另外下载，Keil 自带。

  1. 打开 C:\Keil_v5\ARM\STLink\USBDriver
  2. 64 位系统运行 dpinst_amd64.exe，32 位运行 dpinst_x86.exe
  3. 把 ST-Link V2 插到电脑 USB 口
  4. 右键开始菜单打开设备管理器，看到 STMicroelectronics STLink 就成了
接线

ST-Link 和最小系统板之间要接四根杜邦线，一一对应接：SWDIO、SWCLK、GND、3.3V。教程里有接线图，照着接，别接反。

5

新建工程对应 P4

这一步跟着教程视频做，下面只说环境相关的关键点和最容易卡住的地方。

  1. 菜单 Project → New µVision Project
  2. 存到纯英文路径，比如 D:\stm32\Project01，文件夹名和工程名都别用中文
  3. 弹出 Select Device 窗口，展开 STMicroelectronics → STM32F1 Series，一层层点到 STM32F103C8，点中它
  4. 下一个窗口 Manage Run-Time Environment 直接点 Cancel，教程用标准库，不用这里的组件
  5. 按教程把标准库文件复制进工程，库在本包 02-标准库 里，或者用官方资料包里那份，两者一样
  6. 按教程添加分组、添加头文件路径
  7. 定义宏 USE_STDPERIPH_DRIVER，位置在魔术棒图标 → C/C++ 标签 → Define 输入框
别被 unknown 吓到

Select Device 窗口刚打开时，上面 Vendor、Device、Toolset 三行都显示 unknown。这是正常的，因为还没选芯片。在下面树里点中一个具体型号，三行会立刻自动填好。

做完的标志编译通过，0 Error 0 Warning
6

配置下载器并烧录

  1. 点工具栏的魔术棒图标，打开工程设置
  2. 进 Debug 标签，右上角下拉框选 ST-Link Debugger
  3. 点旁边的 Settings，如果右边能读出一串 SW Device 编号，说明板子连上了
  4. 进 Flash Download 标签，勾上 Reset and Run，这样烧完自动运行，不用手动按复位
  5. 回到主界面，点下载按钮，看到 Verify OK 就成功了
全部完成可以开始 P5 GPIO 输出了

出错了怎么办

芯片列表是空的，只有一项 ARM

器件包没装上，或者被删掉了。

  1. 回到第 3 步，双击 .pack 文件离线安装
  2. 装完必须完全退出 Keil 再重开，否则列表不刷新

Pack Installer 顶上出现红色 ERRORS，写着 Cannot load PDSC Files

在线目录缓存下坏了。那些是从网上下的芯片索引文件，下载中断或者被网络拦截，存下来就是坏的。

  1. 完全关掉 Keil 和 Pack Installer
  2. 打开 C:\Keil_v5\ARM\PACK\.Web，把里面的文件全部删掉。这个文件夹只是缓存，删了不影响已装的东西
  3. 重开 Keil，改用第 3 步的离线方式装包

那个 ERRORS 下面的 Del 按钮删的是坏缓存，点了是安全的。但 Packs 标签页里已经装好的器件包千万别删。

编译报一大堆错，说找不到头文件或者符号未定义

新建工程最常见的两个疏漏，按顺序查：

  1. 宏没定义。魔术棒 → C/C++ 标签 → Define 框里必须填 USE_STDPERIPH_DRIVER。少了它标准库的头文件全部不生效，会报几十上百个错
  2. 头文件路径没加。同一个 C/C++ 标签里，Include Paths 要把工程中每个放了 .h 的文件夹都加进去，一个都不能漏
  3. 路径里有中文或空格，也会导致找不到文件，工程要放纯英文路径

点下载报错，找不到 ST-Link 或者 No target connected

  1. 确认驱动装了，见第 4 步
  2. 确认四根杜邦线接对：SWDIO、SWCLK、GND、3.3V，接反了读不到芯片
  3. 确认用的是数据线，有些 USB 线只能充电不能传数据
  4. 魔术棒 → Debug 标签，下拉框要选 ST-Link Debugger，不是默认的 ULINK

编译报错说超过 32K 限制

MDK-Lite 免费版的容量上限。跟着教程学到后面才会撞上，遇到了再去 Arm 官网申请 MDK Community Edition，非商业用途免费，装上就没有限制。申请完在 Keil 里点 File → License Management 填授权码。

关于这个教程

江协科技的 STM32 入门教程 2023 版一共 50 集。P1 到 P2 是介绍，P3 讲软件安装，P4 讲新建工程，从 P5 开始才真正写代码。前四集是纯配置，卡住很正常，过了就顺了。

它用的是标准库不是 HAL 库。这两套是不同的写法，网上搜到的代码如果是 HAL 的，直接抄进来编译不过。搜资料时注意区分。

器件包来自 Keil 官方源，标准库为 ST 官方 V3.5.0 版，均已校验完整。卡在哪一步，把那一步的截图发回来。
